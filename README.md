VRCSquish allows you to place Squish Zones on your avatar that react to the touch of other players.


This module was developed with Poiyomi 9.2.6 in mind. I have no plans to port it to newer versions which break compatibility.

Go to: Ahoya -> VRCSquish in the toolbar to begin.
