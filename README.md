# VRCSquish v1.0
VRCSquish allows you to place Squish Zones on your avatar that depress to the touch of other players.

## Where To Start
Go to Ahoya -> VRCSquish in the toolbar to begin.

## Credits
- Main Development - Ahoya

## Compatibility Warning
### Working Poiyomi Versions:
- Poiyomi Pro v9.0.x
- Poiyomi Pro v9.1.x
- Poiyomi Pro v9.2.x
- Poiyomi Pro v9.3.41

I have no plans to port it to other versions and cannot guarantee functionality on anything newer/older. If someone else would like to port it, feel free.

Do not import this package into your project unless you have one of the listed versions. 

**Non-Pro versions of Poiyomi do not work with this module.**
